# 矿大校园网一键助手 · campus-net-helper

中国矿业大学南湖校区校园网（`CUMT_Stu`）的 Windows 小工具：一键切 5GHz、等 IP 就绪、判断是否已认证、需要时打开认证页；再附一个「切回手机热点」的退路脚本。

> ⚠️ **非学校官方工具**，与信息化建设与管理处无关。脚本全部在本机跑，不上传任何数据，也不需要管理员权限；**账号密码只由你自己在认证页里输入**，仓库里不含任何账号信息。

## 文件

| 文件 | 作用 |
| --- | --- |
| `校园网一键登录.bat` | 连 `CUMT_Stu` → 等 IPv4 就绪 → 查频段（掉 2.4GHz 自动重连一次）→ 探测认证状态 → 未认证则弹 `9.9.9.9` 认证页（按 `R` 重开页面 / 按 `Q` 结束）。同目录若有 `校园网络助手.exe`，会优先用它自动登录 |
| `切5G校园网.bat` | 早期版本，只做「切网 + 开认证页」，逻辑更简单 |
| `恢复到手机热点.bat` | 校园网连不上 / 半夜断网时切回手机热点 |

## 用法

1. 克隆或下载本仓库，双击想要的 `.bat` 即可（不需要管理员权限，只调用 `netsh wlan` / `ipconfig` / `curl`）。
2. 每个脚本顶部都有配置块：`SSID`（默认 `CUMT_Stu`）、`HOTSPOT`（改成你自己的手机热点名）。**把 SSID 改成你学校的名字，这套脚本对其他学校一样能用**（认证页地址 `MENTER` 也要改）。
3. 脚本是 **GBK 编码 + CRLF 换行**：直接双击没问题；在 GitHub 网页上看中文会乱码，属正常现象（`chcp 936` 下的中文 Windows 批处理就得这么存）。

## 为什么脚本要「等 IP 就绪」才开认证页

学校门户 `9.9.9.9`（或 `go.cumt.edu.cn`）是**未认证时被网络拦截**才出现的页面，表单里嵌着**你当时的 IP**。如果 IP 还没定下来就打开页面，你慢慢输完账号密码再点登录，门户那边拿到的 IP 已经和页面对不上，它就**静默不理你**——现象就是「输完点登录什么反应都没有，重跑一次又好了」。

所以 `[3/6]` 那一步会先轮询 `ipconfig` 拿到 IPv4 再继续；`[4/6]` 那一步发现掉到 2.4GHz 会断开重连一次（实测那个 2.4GHz 节点只有几十 KB/s，基本不可用）。

## 原理：不想开浏览器手动登录怎么办

矿大认证的后端是 **Dr.COM eportal**，浏览器认证页提交的就是这个接口：

```
http://10.2.5.251:801/eportal/?c=Portal&a=login&login_method=1
    &user_account=<学号>@<cmcc|unicom|telecom>
    &user_password=<密码>
    &callback=dr<毫秒时间戳>&_=<毫秒时间戳>
```

- 成功返回：`({"result":"1","msg":"认证成功"})`
- 注销：`http://10.2.5.251:801/eportal/?c=Portal&a=logout`
- 运营商后缀：移动 `cmcc` / 联通 `unicom` / 电信 `telecom`

这个接口在校内是公开可见的（浏览器 F12 看认证页发出的请求就能抓到）。知道原理以后，你可以自己写十几行 `curl` 或 PowerShell 定时任务来完成自动登录——本仓库的脚本之所以只做「探测 + 开页面」，就是因为**把密码写进脚本会明文落盘**。

## 常见问题

- **认证成功后 `9.9.9.9` 打不开**：正常。认证页只在未认证状态下存在，认证后它就下班了。
- **提示「终端IP已在线」/「登陆超限」**：账号被旧终端占着。去 `9.9.9.9` 的「自助服务 → 在线状态」下线旧终端，或让手机先退出校园网，然后断开重连再登。
- **一个账号最多 3 个终端同时在线**：别同时拿网页和自动脚本各登一次，容易把自己顶掉。
- **周日–周四 23:30 至次日 07:00 停止上网认证**：半夜 Wi-Fi 断是政策，不是故障。
- **选了「校园网」线路只能访问校内资源**：要上外网（或走手机套餐）请在认证页选「运营商」线路。
- **报修**：400-008-9233 / 83592139 / 83592122；南湖校区桃 2 楼学生事务综合服务中心网络运维窗口。

## 关于网上流传的 `校园网络助手.exe`

校园里流传的 `校园网络助手.exe`（出自学生社团「翔工作室」的矿小助团队，未签名的 C++ 程序）确实能自动登录，但**本仓库不附带任何二进制**，原因三条：

1. 它不是本仓库作者的代码，**转发别人未授权的二进制不合适**；
2. 没有源码，谁也无法审阅，放进公开仓库等于让读者无条件信任一个黑盒；
3. 它会把账号密码**明文**写进 `C:\Users\Public\Documents\user.info`——这个目录本机任何账户都能读。公开仓库里挂一个「要你填统一身份认证密码的可执行文件」，是最容易被拿去仿冒、钓鱼的形态，对你对读者都不好。

需要它请到作者自己的渠道获取。脚本会把**你自己**放在同目录（或 `%USERPROFILE%\Downloads`）的 `校园网络助手.exe` 当作可选的自动登录器，找不到就退回网页认证——**不依赖它也能用**。
